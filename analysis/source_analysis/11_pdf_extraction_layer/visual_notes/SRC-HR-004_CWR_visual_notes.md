# Visual Notes — CWR.pdf (SRC-HR-004)

> **Form**: Contract Worker Requisition (Outsourcing) | **Pages**: 4 | **Department**: HR

## Structure

**Two parallel worker sections**:
1. Permanent/Temporary Contract Workers (Requirement Details)
2. Plant Shutdown Contract Workers (Requirement Details)

Each with: Site, No. of Workers, Section, Job Description, Period Required (3 date rows)

**4-stage approval**:
1. Endorsed by HOD — Approved/Rejected + HODApp
2. Approved by Division Head — Approved/Rejected + HODApp3
3. Acknowledged by AGM HR — Approved/Rejected + HRApp
4. Acknowledged by Requestor — Acknowledge/Deny + HODApp2

**HR/MTN fill section**: Vendor, Number of pax, Required Due date, Request Status

**Note**: "To issue form to HR minimum 2 months in advance!"

**Workflow signals**: CurrentAction, SendTo (routing to HOD), Editor1-4

**Child List Candidates**: Period Required date rows (1-3) in both worker sections
