# Migration Review Checklist

## Source Review
- [ ] All Domino forms identified and documented
- [ ] All fields inventoried (name, type, size, formula)
- [ ] All views identified and analyzed
- [ ] All agents/scripts reviewed
- [ ] PDF UI screenshots matched to forms
- [ ] Workflows documented (manual and automatic)

## Target Design
- [ ] SharePoint list columns match Domino fields
- [ ] Choice/option values migrated
- [ ] Lookup relationships designed
- [ ] Calculated fields replicated
- [ ] Validation rules implemented
- [ ] Permissions designed
- [ ] Power App screens match Domino UI flow

## Data Migration
- [ ] Field mapping complete (CSV)
- [ ] Data transformation rules defined (CSV)
- [ ] Data types compatible
- [ ] Key fields identified for matching/merging
