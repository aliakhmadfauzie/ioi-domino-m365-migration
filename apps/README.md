# Apps

The application source lives in **separate git repositories**, referenced here for organization:

- `code-first/ioicodeapp/` — Power Apps **code-first** app (React 19 + TypeScript + Vite + shadcn/ui). Its own git repo.
- `canvas/` — Power Apps **canvas** app (`.pa.yaml` screens + design docs). Its own git repo.

Each subfolder is a standalone git repository. Do not commit their contents from this repo.
